🛍️ Shopify

1

Crea una app en Shopify

Ve a dev.shopify.com → Create App → Nombre: "WhatsApp Bot"

2

Copia el API Key y Secret

Configuration → API credentials → Client ID y Client Secret

3

Configura los permisos (Scopes)

read_products, write_products, read_orders, write_orders, read_customers, write_customers

Solo la URL de tu tienda
Client ID de tu app en dev.shopify.com
Client Secret de tu app en dev.shopify.com

🔄 Cómo funciona:

1. Ingresa URL, API Key y API Secret
2. Click en "Conectar"
3. Se abrirá Shopify para autorizar
4. ¡Listo! El token se guarda automáticamente
5. Click en "Sincronizar Productos"
